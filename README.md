# DesignRoom

Интерактивный 3D-конструктор комнаты на Unity. Пользователь задает размеры помещения, размещает мебель по клеткам пола, поворачивает предметы и меняет материалы стен.

Учебный проект посвящен инструментам редактирования сцены: генерации геометрии из префабов, выбору объектов лучом и переключению режимов работы через интерфейс.

## Возможности

- Создание комнаты по ширине и длине, заданным в меню.
- Проверка параметров: размер от 3×3, название от 3 до 8 символов.
- Выбор предметов из категорий мебели, рабочего места и декора.
- Размещение предмета по центру выбранной клетки пола.
- Поворот объекта на 90°, удаление и смена материала стены.

## Техническая реализация

**Стек:** Unity 6, C#, Physics Raycast, Unity UI, TextMeshPro.

Генерация комнаты и обработка инструментов находятся в отдельных компонентах. Режим редактора задается перечислением `EditMode`; результат raycast обрабатывается в соответствии с выбранным инструментом.

| Код | Назначение |
| --- | --- |
| [MainMenu.cs](Assets/Scripts/MainMenu.cs) | Ввод, проверка размеров и названия |
| [RoomSettings.cs](Assets/Scripts/RoomSettings.cs) | Передача параметров комнаты между сценами |
| [RoomBuilder.cs](Assets/Scripts/RoomBuilder.cs) | Создание пола, стен и платформы из префабов |
| [RoomEditController.cs](Assets/Scripts/RoomEditController.cs) | Выбор поверхности и операции над объектами |
| [ButtonsManager.cs](Assets/Scripts/ButtonsManager.cs) | Интерфейс выбора инструментов |

Для просмотра основной логики достаточно `RoomBuilder` и `RoomEditController`: первый создает помещение, второй обрабатывает действия пользователя.

## Запуск

1. Откройте проект в Unity 6000.0.58f2.
2. Откройте сцену **MenuScene** и нажмите **Play**.

## Управление

Задайте параметры комнаты и нажмите **Start**. Выберите **Objects**, **Material**, **Rotate** или **Delete**, затем нажмите на соответствующий объект или поверхность. В редакторе используется левая кнопка мыши.
